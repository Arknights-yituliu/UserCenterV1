# 干员数据统计接口

面向公开调用方的只读接口，返回《明日方舟》干员养成数据的全量统计结果（各属性取值分布）。

统计结果由服务端离线跑批生成并落库，接口只读结果表，**不会触发全表扫描**，响应耗时与源表数据量无关。

## 1. 基本信息

| 项目 | 说明 |
|---|---|
| Base URL | `http://<host>:<port>` |
| 接口路径 | `GET /open/ak-operator-statistics/result`（V1）<br>`GET /open/ak-operator-statistics/v2/result`（V2，字段差异见第 5 节） |
| 鉴权 | 否（公开接口，`/open/**` 不在会话或 OAuth 拦截器范围内） |
| 请求参数 | 无 |
| 返回格式 | `application/json`，统一封装为 `{ code, msg, data }` |
| 成功标识 | `code = 200` |
| 实现类 | `com.orange.controller.open.AkOperatorStateStatisticsController` |

统一响应结构：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": []
}
```

## 2. 请求说明

- 无任何 Query、Path 或 Body 参数。
- 接口返回结果表中全部干员的统计数据，按 `charId` 升序排列；干员数量为几百条量级。
- 一次请求返回整份结果，不支持按干员过滤或分页。

## 3. 响应 data

`data` 为对象数组，一行对应一个干员、只包含最近一轮统计结果。

| 字段 | 类型 | 说明 |
|---|---|---|
| charId | string | 干员编码，对应 `ak_operator_state.operator_id` |
| own | number | 拥有该干员的记录总数（仅 `owned = 1` 的记录参与统计） |
| sampleSize | number | 有效样本数：最近一次数据变更时间不早于该干员实装时间的游戏账号数；未匹配到实装时间的干员记 0 |
| elite | object | 精英化阶段分布（对应 `evolve_phase`），key 为阶段取值、value 为记录数 |
| skill1 | object | 技能 1 等级或状态分布 |
| skill2 | object | 技能 2 等级或状态分布 |
| skill3 | object | 技能 3 等级或状态分布 |
| modA | object | A 模组数值分布（对应 `equip_a`） |
| modX | object | X 模组数值分布（对应 `equip_x`） |
| modY | object | Y 模组数值分布（对应 `equip_y`） |
| modD | object | D 模组数值分布（对应 `equip_d`） |
| modB | object | B 模组数值分布（对应 `equip_b`） |

分布对象的结构固定为 `{ "<取值>": <记录数>, ... }`，例如 `{"0": 25212, "1": 3273, "2": 3091}`。

统计口径补充：

- 每个干员的 9 个分布分别求和，均等于该干员的 `own`；
- 分布字段不会是 `null`，无数据时输出空对象 `{}`；
- 干员实装时间取自外部数据 `https://ark.yituliu.cn/json/operator_update_time.json`，账号时间取自 `ak_operator_state` 的 `MAX(updated_at)`。

## 5. V2 接口

`GET /open/ak-operator-statistics/v2/result`

请求方式、鉴权、响应结构、排序规则与 V1 完全一致，仅模组分布字段改用源表列名命名：

| V1 字段 | V2 字段 | 说明 |
|---|---|---|
| modA | equipA | A 模组数值分布（对应 `equip_a`） |
| modX | equipX | X 模组数值分布（对应 `equip_x`） |
| modY | equipY | Y 模组数值分布（对应 `equip_y`） |
| modD | equipD | D 模组数值分布（对应 `equip_d`） |
| modB | equipB | B 模组数值分布（对应 `equip_b`） |

`charId`、`own`、`sampleSize`、`elite`、`skill1`、`skill2`、`skill3` 字段与 V1 相同。

## 6. 调用示例

```bash
curl "http://localhost:8080/open/ak-operator-statistics/result"
curl "http://localhost:8080/open/ak-operator-statistics/v2/result"
```
