# 排班表接口文档

## 数据约定

- 排班表以 JSON 数组提交和返回；每个数组元素代表一条排班记录，且必须为 JSON 对象。
- 当前版本不固定排班记录内部字段，以兼容不同业务的日期、时段、状态等字段。客户端应使用稳定字段名，例如 `date`、`time`、`status`。
- 单个 JSON 字符串最大 30KB；每个用户最多保存 5 个排班表。
- 创建时不传 `id`；更新时传现有 `id`，内容按完整排班表覆盖。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/user/schedules/save` | 当前用户 | 创建或覆盖更新自己的排班表，返回排班表 ID。 |
| GET | `/user/schedules/list?username={username}` | 当前用户 | 仅当 `username` 属于当前用户时返回完整排班表列表。 |
| POST | `/user/schedules/delete` | 当前用户 | 删除自己的排班表。 |
| GET | `/schedules/{id}` | 无 | 按 ID 返回完整排班表。 |

### 保存请求示例

```json
{
  "schedule": [
    {"date": "2026-09-21", "time": "09:00-18:00", "status": "on_duty"}
  ]
}
```

更新时额外传入 `id`。
