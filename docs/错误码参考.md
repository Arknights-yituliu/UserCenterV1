# UserCenter 错误码参考

本文档汇总 `ResultCode` 中定义的全部业务错误码。具体接口文档中的约定优先于本表；调用方应始终检查响应体中的 `code`。

## 1. 响应约定

- `200` 表示业务成功。
- `BusinessException` 默认返回 HTTP `200`，错误信息放在响应体的 `code` 和 `msg` 中。
- 参数校验失败通常返回 HTTP `400` 和 `code=10002`。
- 用户配置并发冲突返回 HTTP `409` 和 `code=10005`。
- 未处理的服务端异常返回 HTTP `200` 和 `code=40001`。

## 2. 参数与配置错误

| code | 含义 | 常见场景 |
| --- | --- | --- |
| `10001` | 参数错误 | 不支持的登录方式、授权参数或业务参数 |
| `10002` | 参数校验失败 | 必填字段缺失、长度或格式不符合校验规则 |
| `10003` | 非法操作 | 公共客户端尝试轮换客户端密钥 |
| `10004` | 配置存储总量超过大小限制（500KB） | 用户配置总量超过配额 |
| `10005` | 配置已被更新 | 配置创建冲突或 CAS 更新冲突 |

## 3. 账号错误

| code | 含义 | 常见场景 |
| --- | --- | --- |
| `20001` | 用户不存在 | 登录或兑换用户信息时找不到用户 |
| `20002` | 密码错误 | 密码登录失败 |
| `20003` | 该邮箱已被注册 | 注册或换绑邮箱时邮箱已占用 |
| `20004` | 账号已被封禁 | 被封禁账号尝试登录 |
| `20005` | 账号不能为空 | 账号为空（当前部分流程使用 `10001`） |
| `20006` | 该账号未绑定邮箱 | 重置密码或发送邮箱相关验证码时未绑定邮箱 |
| `20007` | 该用户名已被注册 | 注册时用户名已占用 |

## 4. 验证码与限流

| code | 含义 | 常见场景 |
| --- | --- | --- |
| `30001` | 验证码错误 | 提交了错误的邮箱验证码 |
| `30002` | 验证码已过期，请重新获取 | 提交了过期验证码 |
| `30003` | 验证码发送过于频繁，请稍后再试 | 触发邮箱验证码发送频控 |
| `30004` | 登录失败次数过多，账号已临时锁定 | 登录失败达到锁定阈值 |
| `30005` | 请求过于频繁，请稍后再试 | 触发 IP 或接口限流 |

## 5. 系统与会话错误

| code | 含义 | 常见场景 |
| --- | --- | --- |
| `40001` | 系统繁忙，请稍后再试 | 未处理的服务端异常或服务端配置异常 |
| `40002` | 验证码发送失败，请稍后再试 | 邮件渠道发送失败 |
| `80001` | 未登录或登录已失效 | 缺少、无效或已失效的用户/OAuth 会话凭证 |
| `80002` | 登录已过期，请重新登录 | 预留会话过期码，当前实现通常使用 `80001` |
| `80008` | 无权限操作 | 操作不属于当前用户的数据 |

## 6. OAuth2 错误

| code | 含义 | 常见场景 |
| --- | --- | --- |
| `90001` | OAuth 客户端不存在或已停用 | `client_id` 不存在、所有者停用或客户端配置无效 |
| `90002` | 回调地址不在白名单内 | `redirect_uri` 与登记值不完全一致 |
| `90003` | 请求的权限范围未授权 | 请求了客户端未批准的 `scope` |
| `90004` | 授权码无效或已过期 | 缺少、过期或不匹配的授权码 |
| `90005` | 授权码已被使用 | 重复兑换同一个授权码 |
| `90006` | 授权类型不支持 | 客户端未登记该 `grant_type` |
| `90007` | 客户端密钥校验失败 | 加密客户端密钥缺失、错误或已轮换 |
| `90008` | PKCE 校验失败 | `code_verifier` 或 PKCE 配置不匹配 |
| `90009` | OAuth 令牌无效、已过期或已被使用 | refresh token 失效，或 OAuth 令牌校验失败 |
| `90010` | 登录票据无效或已过期 | 预留的跨站登录票据错误码 |
| `90011` | 授权确认单无效或已过期，请重新发起授权 | 授权确认单不存在、过期或被重复提交 |
| `90012` | 客户端数量已达上限 | 当前用户无法继续注册客户端 |
| `90013` | OAuth 客户端待管理员审批或已被封禁 | 客户端尚未审批或被管理员控制 |
| `90014` | OAuth 客户端未开通直连认证能力 | 直连登录或直连注册未获管理员开通 |

两份 OAuth 接入文档面向授权码、令牌和用户信息流程，不要求接入方直接调用 `/oauth2/ticket`、`/oauth2/consent/info` 或 `/oauth2/consent`；因此 `90010`、`90011` 主要供 UserCenter 内部授权页面流程参考。
